Flash firmware to your O3C — no tools required

Connect your Sayobot O3C in bootloader mode and flash SayoFW directly from this page. No drivers, no CLI, no installs — just Chrome/Edge and a USB cable.

1

Enter Bootloader Mode

  1. Unplug the O3C from USB
  2. Hold the BOOT0 button (small button on PCB)
  3. While holding BOOT0, plug in the USB cable
  4. Release BOOT0 — device is now in ISP mode

💡 The OLED will stay blank — that's normal in bootloader mode.

🌐 Supported Browsers

  • Chrome 61+ (Windows, macOS, Linux, ChromeOS)
  • Edge 79+ (Windows, macOS)
  • Opera 48+

Firefox and Safari do not support WebUSB.

🔧 Driver Notes

  • Windows: WinUSB driver required — Install via Zadig
  • macOS: No driver needed
  • Linux: Add udev rule for VID 4348

🛟 Recovery

Can't brick it — if firmware has invalid MD5, the bootloader stays in ISP mode automatically. Just re-flash.
